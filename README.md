# Domain Extention

Многофункциональное AI-приложение с умным ассистентом-персонажем.

Приложение — клиент к нейросети (например, ChatGPT). Модель отвечает
в стиле выбранного персонажа, управляет заданной 2D/3D-моделью и вызывает
API умного дома в фоновом режиме.

> Дизайн может быть хаотичным и не следовать общим стандартам:
> это индивидуальный подарок одному человеку.

---

## Возможности

- **Голосовое общение** — тот же голос и интонации, что у персонажа
  в оригинальном аниме или сериале
- **Движения на месте** — жесты, которые ему были бы характерны
  в конкретный момент
- **Ассистент** — поиск информации, разговоры о личном и всё,
  что умеет современная нейросеть, но в стиле персонажа
- **Умный дом** — агент вызывает переданные ему API
  и не тратит токены на саму команду
- **Перемещение по дисплеям** — телевизоры, мониторы, проекторы

## MVP

В первую очередь:

- голосовое общение в стиле персонажа
- предварительный дизайн
- персонаж **Рёмен Сукуна** из аниме «Магическая битва»
  в озвучке Studio Band

- одностраничник с меню

## Архитектура

| Инструмент | Роль |
| --- | --- |
| **BLoC** | состояние экранов и фич |
| **Clean Architecture** | слои `data` / `domain` / `presentation` |
| **go_router** | навигация |
| **автогенерация** | кодген (`build_runner` и дальше) |

### Правило файлов

- `IFile` — абстракция / интерфейс
- `File` — реализация, зависит от интерфейса
- оба файла лежат **в одной папке**
- один файл — одна ответственность

## Структура

```text
assets/characters/{id}/
  character.yaml               # id, locale, remote voice id
  prompts/                     # system / tools / examples / post_history
  voice/
    manifest.yaml              # canned + cloned voice
    reference/                 # короткие клипы для регистрации голоса
    canned/                    # готовые фразы UI

lib/
  app/                         # оболочка приложения
    router/                    # go_router
    theme/                     # темы персонажей
    profile/                   # поведение персонажей
  core/                        # общее ядро
    failure/
    usecase/
  features/
    shell/                     # одностраничник с меню
    assistant/                 # чат, live-сессия, tools
    voice/                     # клон голоса и живой разговор
    character_stage/           # модель и движения на месте
    smart_home/                # устройства и ручное управление
    display/                   # переход между дисплеями
    home_widget/               # виджеты iOS / Android
```
